MS Sans Serif.ttf / MS Sans Serif Bold.ttf
===========================================

The FontStruction "MS Sans Serif" (https://fontstruct.com/fontstructions/show/1384746)

These files were obtained from the XP.css project
(https://github.com/botoxparty/XP.css), under `gui/fonts/src/`, and are used as the
Luna.Avalonia theme's fallback UI font.

Modifications
-------------

The files in this folder are MODIFIED versions of the originals. Only font metadata
was changed; the glyph outlines (the drawn letters) are identical to lou's originals:

- Both files: the family name was changed from "MS Sans Serif" / "MS Sans Serif
  Bold" to "Luna MS Sans Serif" (name table; the full and PostScript names follow
  it), so the font no longer collides with the Windows system bitmap font of the
  same name.
- MS Sans Serif Bold.ttf: additionally marked as the Bold face of that family
  (OS/2 usWeightClass 400 -> 700 and bold flags in OS/2 fsSelection and head
  macStyle), and its character map (cmap table) was rewritten by the editing tool.

These modified files remain licensed under CC BY-SA 3.0, as their embedded license
fields still state.
